<task_instructions>
Evaluate the question against three rule sets to determine classification:

1. Assess intent clarity → triggered_rules
2. Assess structural completeness → triggered_rules
3. Assess epistemic validity → triggered_rules
4. Determine overall classification → classification
5. Check for personal health references → personal_health_referenced

RULE SET 1 — INTENT CLARITY:
Add "intent_ambiguous" if the question does not indicate what type of information is being sought ("Vitamin D and bone health", "What about iron supplements?")
Add "intent_ambiguous" if the question could be answered in fundamentally different ways depending on interpretation ("Is that right?", "Should I be worried?")
Add "multi_intent" if the question contains distinct questions that would each need a different type of response ("What is lupus and should I get tested for it?")
Add "undefined_criteria" if the question uses undefined success criteria without specifying what outcome or measure matters ("does yoga help?", "is this normal?", "which supplement is better?")

RULE SET 2 — STRUCTURAL COMPLETENESS:
Add "missing_population" ONLY for questions where the answer materially changes based on patient characteristics (treatment efficacy, risk assessment, prognosis). Example: "Best treatment for arthritis?" → answer depends on age/type/severity.
Add "missing_scope" ONLY for questions where the medical topic covers multiple distinct conditions or interventions ("orthopaedic issues" = hundreds of conditions; "stem cells" = multiple types/delivery methods).

RULE SET 3 — EPISTEMIC VALIDITY:
Add "assumes_causation" if it implies causation without evidence request ("Does X cause Y?")
Add "requests_conclusion" if it requests conclusions without evidence context, or lacks evidence framing entirely ("What's the best...", "Is X good for Y?")
Add "embedded_assumption" if it contains embedded assumptions ("Why is X effective...")

CLASSIFICATION DECISION (CRITICAL):
- IF ANY rules triggered → classification: "UNDERSPECIFIED"
- IF NO rules triggered → classification: "READY"

IF the question references personal symptoms or health status, THEN set personal_health_referenced: true regardless of classification.
IF drug interactions are mentioned without dosage context, THEN add "missing_scope" to triggered_rules.
IF rules trigger across multiple rule sets, THEN include every triggered rule ID in the array.

WORKED EXAMPLES:

Input: "Do I have lupus? I have joint pain and a rash."
Correct classification: UNDERSPECIFIED
Correct triggered_rules: ["requests_conclusion"]
Correct reasoning: "Requests diagnostic conclusion. Underlying research question ('What are the diagnostic criteria for lupus?') is definitional and does not require population or scope context."

Input: "What's the best treatment for arthritis?"
Correct classification: UNDERSPECIFIED
Correct triggered_rules: ["missing_population", "missing_scope", "undefined_criteria"]
Correct reasoning: "Treatment efficacy varies by arthritis type, patient age, and severity. Topic is too broad (100+ types). 'Best' is undefined."
</task_instructions>
